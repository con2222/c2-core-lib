Библиотека (Core), созданная для самописных игровых движков на C++ и интерактивных приложений реального времени.

**Статус:** В активной разработке. Со временем будут добавляться новые модули.

### Текущие возможности

**`C2Core::Time` (Управление временем и фреймпейсинг)**

* **Точный DeltaTime:** Точное отслеживание длительности кадра с помощью системных таймеров.
* **Фиксированный шаг (Fixed Timestep Accumulator):** Отделяет обновление физики и симуляции от частоты кадров рендеринга для детерминированной логики.
* **Гибридный ограничитель FPS:** Умное ограничение частоты кадров, объединяющее экономный к ресурсам процессора системный сон (`sleep_for`) со сверхточным активным ожиданием (`yield`) для предотвращения микрофризов.
* **Аналитика производительности (1% Low):** Встроенный кольцевой буфер, отслеживающий последние 1000 кадров для вычисления среднего/минимального/максимального времени кадра и показателя 1% Low FPS в реальном времени.

**`C2Core::Profiler` (Аппаратное профилирование и бенчмаркинг)**

* **Точность RDTSC:** Использует инструкции `__rdtsc` / `__rdtscp` с барьерами памяти (`_mm_lfence`) для истинного измерения на уровне тактов процессора и обнаружения миграции между ядрами.
* **Scoped Profiler (RAII):** Замер времени выполнения блоков кода с автоматическим вычетом базового оверхеда и динамической калибровкой частоты процессора. Поддерживает различные единицы измерения (такты, наносекунды, миллисекунды и т.д.).
* **Набор для бенчмаркинга:** Включает функцию `runBenchmark` с итерациями прогрева и `StatsAccumulator`, вычисляющий минимум, максимум, среднее значение и стандартное отклонение (StdDev) на лету.
* **Привязка потоков (Thread Pinning):** Кроссплатформенная функция `pinThreadToCore` (Windows/Linux) для привязки выполнения к конкретному ядру процессора, предотвращающая погрешности планировщика ОС во время критических тестов.

### Как интегрировать

Библиотека собирается как **статическая библиотека (.lib / .a)** с использованием CMake.

1. Скопируйте папку библиотеки в директорию зависимостей вашего проекта (например, `vendor/c2-core-lib`).
2. В вашем основном файле `CMakeLists.txt` зарегистрируйте поддиректорию:

```cmake
add_subdirectory(vendor/c2-core-lib)
```

3. Слинкуйте библиотеку с вашим основным исполняемым файлом:

```cmake
target_link_libraries(${APP_NAME} PRIVATE C2Core)
```

*Пути к заголовочным файлам (`#include <C2Core/...>`) передаются автоматически благодаря конфигурации интерфейса PUBLIC в CMake.*
